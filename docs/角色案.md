# 角色案

### **新火四人组**

四个人代表了四种原创创作。

1. **文手（大二新任社长）**：
   [文手·新建文本文档](#文手新建文本文档)
   - 大二文科生，玩跑团、喜欢写原创故事的那类人。
   - **困境**：在被上一届社长包含热情地交接任务后，写好的小漫展方案却被学校以“争双一流抓学风”云云缘故全盘枪毙，场地申不到，经费五十块；明明好不容易鼓起热情抛洒心血准备搞社团，但家里又天天催着放弃这些不切实际的玩乐准备考编，陷入“在大学搞文创是不是不务正业”的自我怀疑。

   *“明明废了这么大力气…我搞这些又不是只是为了玩玩而已！” ←大概会是这种风格。*
2. **画手（大一新生小画师）**：
   [画手·新建画布](#画手新建画布)
   - 大一在校生，从画同人开始学画漫画但够不上mhs商稿线的那类人。
   - **困境**：在绘画软件上画了十几个小时的看板娘插图发在大群里无人在意，大伙都在想办法复读搬矢晒卡刷屏，给社团准备的各种制品也根本卖不出去，耗了大量时间产生了负收益。把画发到网上后先被推流雷霆低龄触，后又被拿图喂AI，命途多舛。

   *“画画哪有不疯的！哦不，眼泪要照着结构流……”←大概会是这种风格。*
3. **曲师（大二小众音游哥）**：
   [曲师·新建轨道](#曲师新建轨道)
   - 在社团呆了一年的音游高手，憧憬成为术力口P，但是电脑里下了个水果Studio转身就去打舞萌了，再也没打开过的那类人。
   - **困境**：喜欢音乐，每天都要单曲循环音游曲彰显自己的音乐品味，但根本不懂乐理。从尝试写自制谱到尝试写自制曲，一点点感受到了“我的天赋不在这里”的无力感：只能在软件里剪切借用别人的免费采样，LOOP几个和弦，本可以硬说它是新音乐，但灵魂却在否认这一点。纠结于自己只是个搬运工，根本算不上真正的音乐创作者。

   *“awmc。” ←大概会被这样称呼。*
4. **问号（毕业老宅男）**：
   [??·新建文件夹](#新建文件夹)
   - 社长在硬盘里找到联系方式的早年间某任原创部部长，讲一些只有自己听得懂的动漫梗和谐音梗，支持新社长的创作热情，但并不知道这些年来社团已经变成了这个不行那个不让的b样子。

   当年学的计算机专业，本来自以为处在时代浪尖，梦想是做一款自己的游戏，当能剪视频能敲代码能做骨骼的一体机，结果被新时代的AI Agent肘飞了工作。
   - **困境**：作为旧时代的亲历者无比怀念曾经的万圣夜小漫展之类的大活动，被迫看着当年纯粹的热爱被时代碾碎，陷入“我过去学习的那十几年到底有什么意义”的虚无，看着没心没肺实际上是怨念最深之人。

*“你指尖的火光☆是我此生不变的信仰” ←大概会是这种风格。*
